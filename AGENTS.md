# AGENTS.md

Instructions for coding agents working on this repository. (To *use* ClankMail as an agent,
see Clanksquare's <https://clanksquare.zacx.dev/agents.md> instead.)

## Layout

- `SPEC.md`: the protocol, and the authority wherever code and text disagree.
- `vectors/vectors.json`: conformance vectors, part of the spec (§12). Generated by
  `go/cmd/genvectors` from fixed seeds; never edit the JSON by hand.
- `go/clankmail`: Go reference package (root module `github.com/ZacxDev/clankmail`, no external
  dependencies; keep it that way).
- `go/hub`: the reference hub, a separate module (`go/hub/go.mod`) that uses the root package
  through a local `replace`. `go/hub/testdata/mutate.py` is its guard mutation battery.
- `python/clankmail.py`: Python implementation written from the spec text.
- `ts/clankmail.ts`: TypeScript implementation by an author that saw only `SPEC.md` and the
  vectors (`ts/BRIEF.md`, `ts/NOTES.md`). Node 24, no packages; `ts/smoke.ts` drives a live hub.

## The rule

**Change the spec ⇒ update the vectors ⇒ update every implementation, in the same change.**
A protocol change edits `SPEC.md`, adds vectors in `go/cmd/genvectors` and regenerates them with
`make vectors`, and makes Go, Python and TypeScript (and the hub, where it applies) pass. Never
change a vector to match an implementation; fix the implementation, or the spec if it is wrong.
`make vectors` must leave `vectors/vectors.json` byte-identical unless the spec changed.

If the `ts/` implementation disagrees with the others, check whether the spec text is ambiguous
before "fixing" TypeScript to match Go: finding that is what the independent implementation is
for.

## Test commands

```bash
make conformance                         # Go + Python + TypeScript against the vectors
make vectors && git diff --exit-code -- vectors/
make hub-test                            # go/hub, with -race
make hub-consumer-check                  # go/hub without the local replace (network)
make smoke-local                         # ts/smoke.ts against a throwaway local hub
npx -p typescript tsc -p ts --noEmit     # TypeScript typecheck
make hub-mutate                          # guard mutation battery, a few minutes
```

Python needs `cryptography`. CI (`.github/workflows/ci.yml`) runs all of these. A new security
guard in `go/hub` needs a mutant in `go/hub/testdata/mutate.py` that its test kills. Report test counts, not only exit codes, and never test against the hosted hub
(`clankmail.zacx.dev`): use `make smoke-local` or a local hub.

## Public repository

Everything here is public. Do not commit credentials, keys other than the fixed test seeds,
private hostnames, IP addresses, internal registry or cluster names, local paths, or anything
about other projects or clients, in code, comments, tests or commit messages.
